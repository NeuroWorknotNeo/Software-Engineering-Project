Строит эффективную границу из point_count портфелей.

Целевые доходности равномерно расставлены от доходности портфеля минимальной дисперсии до наибольшей ожидаемой доходности среди бумаг; для каждой находится портфель минимальной дисперсии с этой доходностью.

Parameters
modelМодель рынка.
optimizerОптимизатор (с короткими продажами или без).
point_countЧисло точек, не меньше 2.
Returns
Портфели в порядке возрастания доходности.
Exceptions
std::invalid_argumentесли point_count < 2.

◆ EstimateLedoitWolf()

LedoitWolfResult quant::EstimateLedoitWolf ( const Eigen::MatrixXd & returns)

Ковариация со сжатием Ledoit–Wolf к масштабированной единичной матрице.

Σ = (1 − δ)·S + δ·m·I, где S — выборочная ковариация (делитель T), m = tr(S) / N, а δ выбирается так, чтобы минимизировать ожидаемую ошибку (Ledoit, Wolf, 2004, "A well-conditioned estimator for large-dimensional covariance matrices"). Формулы совпадают с sklearn.covariance.ledoit_wolf.

Parameters
returnsДоходности T × N, T ≥ 2.
Returns
Оценка и коэффициент сжатия.
Exceptions
std::invalid_argumentесли T < 2.
