double quant::callPrice ( const OptionParams &  p)

Цена европейского опциона Call.

C = S·N(d1) − K·e^(−rT)·N(d2), где d1 = (ln(S/K) + (r + σ²/2)·T) / (σ·√T), d2 = d1 − σ·√T.
