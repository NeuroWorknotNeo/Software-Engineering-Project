Detailed Description

Проекционный градиентный спуск — простой эталон для проверки ActiveSetSolver.

Шаг x ← P(x − (Qx + c) / L), где L — наибольшее собственное число Q, а P — проекция на допустимое множество. Проекция реализована только для симплекса {x ≥ 0, x₁ + … + x_N = b}, поэтому решатель принимает задачи с единственным ограничением-равенством вида 1ᵀx = b.
