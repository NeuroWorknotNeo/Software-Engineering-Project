Detailed Description

Оптимизатор с разрешёнными короткими продажами: решения через множители Лагранжа.

GMV: w = Σ⁻¹1 / (1ᵀΣ⁻¹1). Касательный портфель: w = Σ⁻¹(μ − r_f·1) / 1ᵀΣ⁻¹(μ − r_f·1). Граница: w = Σ⁻¹(λ·1 + γ·μ), где λ = (C − B·r)/D, γ = (A·r − B)/D, A = 1ᵀΣ⁻¹1, B = 1ᵀΣ⁻¹μ, C = μᵀΣ⁻¹μ, D = AC − B². Системы решаются разложением Холецкого, без явного обращения Σ.
